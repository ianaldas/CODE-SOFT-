# CODE-SOFT-# Calculator Program

## Description

This is a simple Calculator Program developed in C++ as part of the CodSoft C++ Programming Internship.

The program allows users to perform basic arithmetic operations such as:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)

## Features

* User-friendly input
* Performs four basic arithmetic operations
* Handles division by zero
* Uses switch-case statements

## Technologies Used

* C++
* Visual Studio Code / CodeBlocks / Any C++ Compiler

## How to Run

1. Compile the program using a C++ compiler.
2. Run the executable file.
3. Enter two numbers and an operator.
4. View the result.

## Sample Output

Enter first number: 10

Enter operator (+, -, *, /): +

Enter second number: 5

Result = 15

Number Guessing Game (C++)
Description

This is a simple console-based Number Guessing Game developed in C++. The program generates a random number between 1 and 100 and asks the user to guess it. After each guess, the program provides feedback indicating whether the guess is too high or too low. The game continues until the correct number is guessed.

Features
Random number generation
User input handling
Feedback for high and low guesses
Continuous gameplay until the correct guess
Simple and interactive console interface
Technologies Used
C++
Standard Library (iostream, cstdlib, ctime)
